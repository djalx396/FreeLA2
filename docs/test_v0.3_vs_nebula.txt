FreeLA2 v0.3 against the Nebula OPTO-2A renders (2026-11-23)
============================================================

Same method as docs/test_v0.2_vs_nebula.txt: the plug-in itself runs over all 219 capture signals in capture order
in one instance, with each render's Nebula knob settings and stages. null = residual vs the Nebula output (dB, lower
is closer); lvl = rms of the level / gain-reduction difference in 50 ms windows while the signal plays (dB).

v0.3 changes nothing in the dynamics or the tone. It adds FILTER phase ANALOG / LINEAR and exact alignment of the
filters (v0.2 was up to 36 us early with OVERSAMPLE Off and a filter on). With FILTER OFF the results are identical
to v0.2. With the filters on, the nulls are deeper, most of all in LINEAR (only the ultrasonic content removed by
the filters is left).
