B and C: the filters change the ultrasonic content on purpose, so the nulls are shallower; the level and
gain-reduction behaviour stays the same (within about 0.1 dB). The Clipper at heavy drive differs more with
oversampling because the Nebula clipper aliases and the oversampled one does not.

Fixed in v0.2 after this comparison (v0.1 -> v0.2, same test):
  - Leveler at PEAK REDUCTION 0 lost 0.1 dB (COMP) / 0.25 dB (LIMIT): now 0.04 / 0.07 dB; Leveler-only null -23.6 -> -47 dB.
  - Short gain-reduction spikes (up to 17+ dB for a few ms) on drum hits and note onsets at stronger settings:
    gone (GR15 drums: peak 14.5 dB vs Nebula 15.0). Cause: the cell-ripple model let envelope jumps through.
  - Leveler timing refitted on bursts + drums/bass/vocal: program-material GR error 0.83/1.12/1.61 -> 0.73/0.99/1.57 dB
    rms (COMP GR03/08/15), LIMIT 1.11 -> 0.93 dB; burst tests 0.30/0.32/0.36 -> 0.26/0.30/0.33 dB.
  - Static curves re-matched: COMP 0.19/0.05/0.14 dB rms, LIMIT 0.35/0.22/0.27 dB (GR03/08/15).

Remaining differences (known limits):
  - Pre 2nd harmonic: same level, about 90 deg different phase. Nulls at DRIVE +15 about -20 dB, at +30 about -3..-7 dB.
    The Nebula H2 kernel also leaves a low-frequency tail for 250 ms after loud passages (about -58 dB at the centre
    DRIVE, -28 dB at full DRIVE); FreeLA2 has none.
  - Leveler: on long holds it reaches its final gain reduction a little sooner (about 0.3-0.5 dB more GR in the first
    seconds); full-scale tones from silence are grabbed harder at first (HOT section, 1 dB average); drums at GR15:
    a bit more on kick-like hits, 2-3 dB less on snare-like hits.
  - Clipper waveform at heavy DRIVE (level within about 0.5-1 dB).
